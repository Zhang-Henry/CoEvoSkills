# General Background: Interactive PDF Forms

PDFs may store interactive values in AcroForm, XFA, or hybrid form structures.
Names, types, and selectable states are defined by the supplied file, so they
should be inspected at runtime. A saved result should preserve the original
document structure and should be reopened to confirm that semantic field values
were written successfully.

This background contains no facts about the current form, parties, answers,
field paths, button states, or required output. Those details must be derived
from the instruction and supplied files.
