# Normalized Strength Calculation Basics

Bodyweight-normalized strength systems may use different published equations
for different divisions and define a limited input domain. Select the applicable
public equation from supplied metadata and preserve the published coefficient
order and boundary rules.

Resolve fields from headers or a data dictionary rather than fixed spreadsheet
coordinates. Keep source rows and identifiers stable, write requested derived
values in the requested representation, and round only at the final reporting
step. This document supplies no coefficients, current values, column locations,
or expected scores.
