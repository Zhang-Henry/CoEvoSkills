# Seismic Association Basics

Earthquake association combines phase picks from multiple stations using a
declared propagation model and consistent space-time coordinates. Treat channel
records as observations of stations, normalize duplicate station metadata, and
preserve the provenance from each accepted pick to its associated event.

Before association, make coordinate units and vertical sign conventions
explicit. Validate time serialization, physical units, and multi-station support
in the final artifacts. This document supplies no station, time, velocity,
coordinate, parameter, or expected-event value.
